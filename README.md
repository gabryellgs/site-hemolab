🧪 Projeto HemolabRN

Este projeto foi desenvolvido como parte da disciplina de Backend, com entrega em 18 de junho de 2025.
Trata-se da implementação de um site institucional utilizando o framework Django, simulando uma plataforma de apresentação de serviços laboratoriais.

🎯 Objetivo

O objetivo é aplicar conceitos de desenvolvimento backend em Django para construir um sistema funcional que reproduza o design fornecido.
O site deve ser o mais fiel possível ao modelo de referência e atender aos seguintes requisitos:

Estrutura do projeto em Django, com nome hemolabrn.

Todas as páginas do sistema devem estar dentro do app mainpage.

Utilização de templates com extensão (extends), permitindo reaproveitamento de menus e rodapés.

Integração de arquivos estáticos (CSS, JS, imagens).

Implementação de rotas para navegação entre páginas.

Uso de ícones do Font Awesome.

Páginas obrigatórias:

Página inicial: hemolabrn.com/index.html

Serviços: hemolabrn.com/servicos.html

Unidades: hemolabrn.com/unidades.html

⚙️ Funcionalidades

Estruturação backend com Django.

Rotas funcionais para navegação entre páginas.

Reaproveitamento de código com templates base.

Integração de arquivos estáticos.

Uso de ícones externos via Font Awesome.
